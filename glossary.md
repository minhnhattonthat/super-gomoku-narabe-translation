# Glossary - Super Gomoku Narabe Renju (SFC)

Binding for every translator and reviewer. Agents propose additions in reports; only the controller edits this file.

## Rulings (user, 2026-10-15)
- Honorifics: none occur. Name order: Western (Goro Sakata).
- Romanisation: Hepburn without macrons (Goro, Kyogetsu). Renju opening names: the RIF English names.
- Credits: English (roles translated, names romanised).
- Renju terms: standard English renju vocabulary (below). No Japanese loanwords except opening names and the
  dictionary entries that teach a Japanese term (hiku, nobiru, tobu, miseru, fukumu, hameru, natsudome, tengen),
  which are given in quotes with an English gloss.
- Abbreviations: avoid. Prefer engine work (VWF is in, boxes are measured). Flag any forced cut.
- Graphics text: in scope.

## Style rules
- Register: friendly, plain instruction-manual English; short menu labels in Title Case, sentences in sentence case.
- Punctuation map: 「」 -> "...", 。 -> . , ! stays, ? stays. No full-width characters.
- No suffix glued onto a number the game prints ({num}): write "Move {num:00}", never "{num:00}th".
- Kana kept on purpose: password strings and the password kana grid (the game compares them with input).
