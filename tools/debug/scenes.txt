# Debug-tool scene list (tools/debug/warp.py). One [scene] per block:
#   desc: one line          base: scene whose steps run first (its steps are not re-shot)
#   N BUTTONS               route step (emu.py format: hold BUTTONS for N frames; "-" = none)
#   poke ADDR=VAL ..        write WRAM/bus byte(s) once at this point (hex, 24-bit CPU address)
#   hold ADDR=VAL ..        write every frame from this point on
#   lua CODE                run Lua once at this point (helpers W.* in warp.lua)
# Several steps may share a line, separated by ";". Presses are held 8 frames; waits are generous so the
# routes also work on translated builds. RAM map and text ids per scene: docs/re/screens.md.
